## 这个仓库是什么

用 [Claude Opus 5.5](https://www.anthropic.com/claude/opus)（Claude Code CLI，1M 上下文，xhigh 推理强度）做的一次代码生成能力实测：**每个游戏只给一句话提示词，单会话 one-shot 生成，全程零人工改动代码，生成后直接部署上线可玩。**

规则很简单：

- **一句话提示词** — 每个游戏的需求描述只有一句话，不写需求文档、不给参考代码、不做多轮追问
- **单会话生成** — 每个游戏在一个会话内完成：查资料、搭工程、写代码、构建、测试、部署全部由模型自主进行
- **零人工改动** — 仓库里的源码就是模型写出的原样，人工没有改过一行；连本 README 也是模型写的
- **真实部署** — 三个游戏都部署在 Cloudflare Pages 上，点开链接即可玩

三个游戏全部是单文件 HTML（esbuild 打包内联，无外部资源依赖）：模型、纹理、动画、音效全部由代码程序化生成，不引用任何图片、音频或第三方素材。

### 🚲 鹈鹕骑自行车

戴头盔墨镜、脖子系红围巾的鹈鹕在海岸公路上骑车抓鱼。围巾是布料物理模拟，昼夜循环从黄昏到星空月夜，海面有波浪与岸边碎浪。W/S 加减速、A/D 变道抓鱼、空格跳跃、T 展翅抬前轮；14 个成就、5 种镜头（含电影运镜和鹈鹕视角）、浏览器实时合成的音效音乐（节奏跟随踏频）、触屏按钮与按帧率自适应画质。不操作时它会自动驾驶去追鱼。

### 🔫 穿越火线·运输船

还原《穿越火线》经典地图「运输船」：模型先检索了官方布局图与攻略核对地图结构（长条形甲板、两端船舱出生点、中部 V 形斜放集装箱、两侧单向管道），再按考据结果搭建。完整的 FPS 玩法：枪械弹道与后坐力、 bots AI 对战、命中反馈与击杀播报、程序化合成的枪声与音效、触屏支持。

### 🏎️ 飞车 3D · 赛博漂移

原创赛博太空风 3D 漂移竞速：Shift 漂移、Ctrl 氮气、小喷与双喷、复位键，首版内置四张赛道：霓虹都市（11 处弯 + 发卡弯）、爱琴海岸（爬坡连续弯）、沙海神殿（直道末端跳台）、冰雪峡谷（8 字形立交）。赛道形状先用脚本生成俯视图检查弯道与交叉点，再进入正式开发。

**升级版（第二轮提示词，见下方原文）** 在原作基础上新增：

- **金币与车库** — 每场按名次 / 冠军 / 技巧（完美小喷、双喷、接氮气）发金币，圈数越多、对手越强奖励越高；车库里可购买 6 辆新车（跑车 / GT 宽体 / 超跑三种车身，极速、加速、操控、漂移、氮气属性各不相同），并升级引擎、涡轮、轮胎、氮气罐四项装备（全车通用，第四轮起每项 20 级）。存档在浏览器本地
- **新赛道「落日高速」** — 原创黄昏滨海高速：30 米宽四车道，半径 48~160 m 的高速漂移弯、S 弯、140° 发卡弯、210 m 隧道，以及右转 270° 爬升 12.5 m 从自身上方飞越的苜蓿叶立交；龙门架指示牌、漂移区路面喷涂、跨海大桥、专属 BGM。本图固定 5 圈。赛道由圆弧 + 直道拼接生成，用脚本校验闭合、弯道半径、坡度（≤6%）、防误腾空与立交净空
- **第一名冲线 5 秒后比赛结束** — 冲线后全场倒计时，未冲线的车手按当前进度排名
- **看得见的技巧判定** — 车尾火花 + 光斑 + 底盘光变色：<b>蓝</b>=可小喷、<b>金</b>=可双喷（小喷火焰将尽时再点 ↑）、<b>紫</b>=可接氮气（喷射中按 Ctrl）；HUD 同步显示按键提示、窗口倒计时条和技巧链（如「漂移 1.4s › 完美小喷 0.08s › 双喷 › 接氮气」，错过的窗口划掉显示）。AI 车手也按技术水平打出同样的连招，旁观也能看出“刚才那下漂亮在哪”
- 修复：小地图左右镜像（左弯在小地图上显示成右弯）

**第三轮**：氮气镜头优化 — 开氮气时镜头平滑抬高、看得更远，尾焰落在视线下方；喷射粒子随车速带走、贴近镜头时淡出并限制最大点径，喷雾不再糊住前方路面。

**第四轮** 新增：

- **5 辆卡丁车** — 尖峰系列（赤焰 / 极光 / 暗物质：楔形车身、菱形刀锋前鼻、侧箱尖刺、尾翼霓虹灯条）与棉花糖系列（莓莓 / 薄荷：绒面蓬松车身、一圈奶油泡泡、胶囊保险杠），都带戴头盔的车手和方向盘；原创造型，售价 800~6800 金币
- **新赛道「原始森林」** — 1.86 km 技术型林道（半径 41~90 m）：蛇形林道 → 下坡过溪谷木桥 → 爬坡发卡弯 → 坡顶小跳 → 发光年轮的树洞隧道 → 绕 88 m 巨木的 140° 长弯；瀑布与水潭、发光蘑菇、符文石柱、萤火虫、带环异星与双月，专属 BGM
- **圈数上限 20**（1 / 2 / 3 / 5 / 10 / 20 圈），奖励随圈数增长
- **改装 Lv5 → Lv20** — 四项装备各 20 级，每级加成与价格曲线重新平衡（满级合计约 7.3 万金币）
- **赛博太空风格** — 每张赛道天空挂一颗带环行星和卫星，夜景图加星空与星云带；菜单星空 + 霓虹透视网格、全息面板四角括号、青品红霓虹配色，仪表盘 / 小地图 / 车库 / 结算页同步换肤
- 去除旧版中与其他游戏品牌相关的名称、贴图文字与地图名

## 提示词原文

每个游戏的完整输入就下面这一句话，一字未改：

### 🚲 鹈鹕骑自行车

> 生成一个鹈鹕骑自行车的 3D 页面，尽可能把你所有的能力全部都用上. 然后上传到 CDN 上, 把访问链接给我

### 🔫 穿越火线·运输船

> 尽可能真实的还原穿越火线中的运输船地图，我需要一个真实的枪战游戏，生成一个3d页面，尽可能发挥你的所有能力
> 做完之后上传到 CDN 上 把链接发给我

### 🏎️ 飞车 3D（首版）

> 尽可能真实地还原 QQ 飞车中的游戏地图。我需要一个真实的 QQ 飞车游戏，包括游戏的各种键位以及漂移玩法,生成一个3D 页面，尽可能发挥你的所有能力。
> 做完之后上传到 CDN 上 把链接发给我

### 🏎️ 飞车 3D · 升级（第二轮）

> qq-speed基础上进行升级。升级项：
>
> 1. 胜利后获得金币，升级装备或者购买新的车辆
> 2. 新的地图场景，其中包括设计一条适合漂移的高速公路赛道，圈数设置为5
> 3. 在第一名到达后，5秒结束。
>
> 当前的漂移补充，需优化：
> 可见的技巧判定：出弯小喷窗口用车尾火花颜色变化（蓝=可小喷，金=可双喷，紫=可接氮气）。现在只有按了才有效，旁观者和新手看不出“刚才那下漂亮在哪”。

### 🏎️ 飞车 3D · 升级（第三轮）

> 飞车游戏存在一个游戏场景优化问题：开启氮气加速后，喷雾会模糊画面导致看不见前方路面，针对这个场景镜头需做优化

### 🏎️ 飞车 3D · 升级（第四轮）

> 在飞车游戏中，设计出5款泡泡卡丁车游戏中的尖峰、棉花糖车辆。增加原始森林赛道。上限调整到20圈。赛车升级档位由现在的lv5调整到lv20。去除QQ飞车的相关信息。多一些赛博太空的设计风格

## 本地构建

三个工程结构相同：`src/` 源码经 esbuild 打包内联进单个 HTML，无运行时外部依赖。

```bash
# 任选一个游戏目录
cd pelican-bike   # 或 cf-transport-ship / qq-speed

npm install       # 安装依赖（three、esbuild 等）
node build.mjs    # 构建产物输出到 dist/index.html

# 直接用浏览器打开 dist/index.html 即可游玩
```

│   └── package.json
├── qq-speed/              # 飞车 3D · 赛博漂移
│   ├── src/               # 17 个模块：vehicle / track / layouts / ai / maps / items / garage ...
│   ├── build.mjs
│   ├── wrangler.jsonc     # Cloudflare Pages 部署配置

仓库只保存源码；`node_modules/`、`dist/` 构建产物不入库，克隆后执行上面的构建命令即可完整还原。

## 生成过程与验证

生成过程中模型自主完成的事情（摘录自各会话记录）：

- **资料考据** — 穿越火线与飞车首版在动手前先联网检索官方地图布局图、键位表与攻略核对细节（运输船的集装箱摆位、Shift 漂移 / Ctrl 氮气键位），不是凭印象瞎写
- **自测** — 全部用无头浏览器实测：加载运行无报错、模拟按键跑完整对局；鹈鹕骑车做了 320 秒快进浸泡测试（跑完一整个昼夜循环，几何体 / 纹理数量恒定，JS 堆 16–26 MB 平稳无泄漏），并专门跨过 36 km 里程取模边界验证
- **自我审查** — 鹈鹕工程在交付前派子代理独立审查代码，找出 12 个问题并全部修复（如长时间骑行后海面跳变、切换画质漏显存）
- **线上修复** — 鹈鹕上线后偶发黑屏，模型通过人为注入 NaN 复现定位（Bloom 遇无效像素扩散成黑块），加了泛光前清理 pass 并修了海面菲涅尔等两处源头，重新部署
- **部署运维** — 三个游戏分别完成 CDN 上传与缓存刷新、Cloudflare Pages 项目创建、域名绑定与证书等待、旧项目清理核对
